# Every symlink this machine should have. Applied by ./link.sh
#
# Format:  <source>  <target>
#   source: relative to this repo, or starting with ~/ for files outside it
#   target: relative to $HOME
#
# A leading ? marks an optional link: it is skipped while its source or the
# target's parent folder does not exist yet. Used when another install creates
# that folder (a program's installer may refuse to run if it already exists).
